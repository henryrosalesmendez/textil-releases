# Textil — Descargas

**Textil** es un editor LaTeX colaborativo: edición en tiempo real, compilación con vista previa PDF, comentarios y asistentes LLM.

- 🌐 **Web**: [www.textilspace.com](https://www.textilspace.com)
- 🚀 **Entrar a la app**: [app.textilspace.com](https://app.textilspace.com)
- ⬇️ **Descargas**: [página de descargas](https://www.textilspace.com/downloads/) o directamente en [Releases](../../releases/latest)

## Instalación

| Plataforma | Archivo | Notas |
| --- | --- | --- |
| Linux | `*.AppImage` | `chmod +x` y ejecutar; universal |
| Linux (Debian/Ubuntu) | `*.deb` | `sudo apt install ./Textil-*.deb` |
| Windows | `*-setup.exe` | Instalador; si SmartScreen avisa: "Más información → Ejecutar de todas formas" |
| Windows | `*-portable.exe` | Sin instalación |
| macOS (Apple Silicon) | `*.dmg` | Primer arranque: clic derecho → Abrir |

Este repositorio solo distribuye los binarios; el código fuente es privado.
